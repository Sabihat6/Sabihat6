# Agile Adoption Timeframe Calculator

A simple website to estimate the approximate adoption timeframe for the Agile framework based on the number of members in an organization unit.

## How to Run

1. Open a terminal in the project directory.
2. Run a local server, for example:
   - Using Python: `python3 -m http.server 8000`
   - Using Node.js: `npx http-server`
3. Open your browser and go to `http://localhost:8000`

## Usage

- Enter the number of members in the input field.
- Click "Calculate Timeframe" to get the approximate adoption timeframe.

The calculation is based on general estimates:
- 1-5 members: 1-3 months
- 6-10 members: 3-6 months
- 11-20 members: 6-12 months
- 21-50 members: 12-24 months
- 51+ members: 24+ months

Note: This is a rough approximation and actual adoption time may vary based on various factors.
